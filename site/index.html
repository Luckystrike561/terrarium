What it does

Agents become characters

Each agent gets its own character. It types at a desk while its agent edits files or runs commands, reads while it searches, and shows the agent's own one-line intent above its head. When the agent needs you, it queues at the CTO's office. When it is idle, it rests in the lounge.

herdr integration

The herdr module shows every agent herdr manages, named after its workspace, with its status, task and pending approvals. herdr servers on other machines join the same office over SSH.

A standalone server

One Node.js process watches your agents and serves the office to any browser. It never modifies your agents: its data lives in ~/.terrarium/, and the only file it writes elsewhere is ~/.claude/settings.json, when you approve Claude Code hooks.

Supported agents

herdr plus agent modules. Pick any combination with --provider, for example --provider herdr,omp,codex. Every agent module shows its CLI's sessions on this machine, with or without herdr.

Approvals means the office shows the agent waiting for your approval. Clean exit means the CLI records its own exit, so the character leaves the moment the session ends. Without it, the character leaves once the session has been quiet for a while. Inside herdr, herdr adds pending approvals for every agent.

Status only in herdr

An agent in a herdr pane whose CLI has no running agent module shows herdr's status, name and task, but no tool activity. That is always the case for Amp, which keeps its threads on ampcode.com, and for agents on herdr servers reached over SSH, whose transcripts are files on the other machine. For every other CLI, add its id to --provider.

Getting started

Requirements: Node.js 22.13 or later (or Docker), and either herdr running locally or one of the supported agent CLIs. Terrarium runs from source. 

git clone https://github.com/Luckystrike561/terrarium.git
cd terrarium
npm install
npm run build

With herdr and omp:

node dist/cli.js --provider herdr,omp

With Claude Code:

node dist/cli.js --provider claude

The server picks a free port and prints a URL like http://127.0.0.1:43123/?token=…. Open it in a browser. Treat that URL as a secret: its token lets a browser install hooks and add connections. The --provider choice is saved in ~/.terrarium/config.json and reused by later runs.

The README covers Docker, the other options and troubleshooting.
